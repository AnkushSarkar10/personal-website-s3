# personal website

the portfolio of ankush sarkar, deployed at [ankushsarkar.dev](https://www.ankushsarkar.dev/).

## search indexing after deployment

1. add and verify `https://www.ankushsarkar.dev/` in google search console.
2. submit `https://www.ankushsarkar.dev/sitemap.xml` in the sitemaps report.
3. inspect the home page url and request indexing after each significant content update.
4. keep the same full name and website url on github, linkedin, x, and other public profiles, and link those profiles back to this site.

search ranking is determined by google. metadata and structured data make the site understandable and indexable, while reputable links and consistent identity signals help it compete for name searches over time.
